# Smart Traffic Violation & Fine Management System

🔗 **Live Website:** https://smart-traffic-system-ef51.onrender.com  
💻 **GitHub Repository:** https://github.com/sidra-shaikh-99/Smart-Traffic-System

## About
A Java-based web application for managing vehicle records, traffic violations, and fines digitally.

## Features
- Admin Login and Dashboard
- Add, View, Update, and Delete Vehicle Records
- Manage Traffic Violations and Fines
- View Fine Payment Status (Paid/Unpaid)
- Search Violations by Vehicle Number

## Technologies Used
- **Frontend:** HTML, CSS, JSP, Bootstrap
- **Backend:** Java Servlets
- **Database:** MySQL
- **Connectivity:** JDBC
- **Server:** Apache Tomcat 9
- **Deployment:** Docker, Render
- **Database Hosting:** Clever Cloud
